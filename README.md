# Приглашение на кыз узатуу — Сани-Рабига Максатбек кызы

Статичный сайт (HTML + CSS + JS, без сборки). Ответы анкеты «Сурамжылоо» пишутся в Google Таблицу.

## Подключить Google Таблицу (5 минут)

1. Создайте новую таблицу на <https://sheets.new>, назовите, например, «Той — гости».
2. В таблице: **Расширения → Apps Script**.
3. Удалите всё в `Code.gs` и вставьте содержимое файла `google-apps-script/Code.gs`. Сохраните (💾).
4. **Развернуть → Новое развертывание** → тип «Веб-приложение»:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   - Нажмите «Развернуть», разрешите доступ к таблице (Google предупредит «приложение не проверено» → «Дополнительно» → «Перейти»).
5. Скопируйте **URL веб-приложения** (`https://script.google.com/macros/s/…/exec`).
6. Вставьте его в `app.js`:
   ```js
   rsvpEndpoint: 'https://script.google.com/macros/s/…/exec',
   ```

Лист «Гости» создастся сам при первом ответе: дата, аты-жөнү, жооп, адам саны (1 / 2 / 0) и итог «Бардыгы» в G1.

> Если позже поменяете `Code.gs` — делайте **Развернуть → Управление развертываниями → ✏️ → Новая версия**, иначе URL продолжит работать со старым кодом.

### Если Apps Script недоступен — через Google Форму

1. <https://forms.new> → два вопроса: «Аты-жөнү» (короткий ответ) и «Жооп» (короткий ответ).
2. Вкладка **Ответы → Связать с Таблицами** → выбрать существующую таблицу.
3. ⋮ → **Получить предзаполненную ссылку** → вписать `ИМЯ` и `ОТВЕТ` → «Получить ссылку» → скопировать.
4. Из ссылки вида `…/forms/d/e/<formId>/viewform?entry.111=ИМЯ&entry.222=ОТВЕТ` вписать в `app.js`:
   ```js
   googleForm: { formId: '<formId>', nameEntry: '111', answerEntry: '222' },
   ```

## Дизайн и музыка

Дизайн по макету из Claude Design: бордовый `#800020` + крем `#FFF5E1`, шрифты Cormorant Garamond и Montserrat.
Цвета меняются в начале `style.css` (`--burgundy`, `--cream`, `--ink`).

Музыка — файл `audio/theme.mp3` (без файла кнопка звука скрывается), старт с `CONFIG.audioStart` секунды.

## Тексты и данные

- Имена, время, адрес, кнопка карты — прямо в `index.html`.
- Дата для таймера и календаря — `CONFIG` в начале `app.js`.
